# DESARROLLO DE SLIDES

Suelo generar mis propios slides para la clases 

En su mayoria solo estan compuestos de images que genero con IA o que obtengo de internet, no son slides sobrecargados de textos sino imagenes(sintaxis,analogias,etc)
Ya que entiendo que una persona presta atencion a una imagen que a solo texto

- Para los prompts de las imagenes : las imagenes deben ser simples pero precisas y autoexplicativas, no debe tener diseño de fondo, sino fondo blanco y lineas o letras en negro , que use colores simples como medios explicativo , esto con el objetivo de no estar sobrecargado de colores sino que usa los colores solo para diferenciar que queremos decir o indicarlo.

> Infografía educativa de programación minimalista sobre "Especificidad en CSS". Estilo limpio y técnico, fondo completamente blanco. Líneas, flechas y textos principales en color negro y gris oscuro. Uso de colores vibrantes (verde, naranja, rojo, azul) ÚNICAMENTE para resaltar los bloques de código y los números de puntaje. Diseño sin adornos de fondo, similar a un diagrama de libro de texto técnico.Estructura visual:
> 
> Título superior en negro: "ESPECIFICIDAD EN CSS (El Sistema de Puntos)".
> 
> Debajo, una estructura de pirámide invertida o escalera de 4 peldaños que va de menor a mayor peso, de abajo hacia arriba.Peldaño 4 (Base, el más ancho): Texto "Etiquetas y Pseudoelementos". Código de ejemplo resaltado <p>, <h1>, div. Puntaje resaltado (0, 0, 0, 1). Etiqueta a un lado: "Menor peso (General)".Peldaño 3: Texto "Clases y Pseudoclases". Código de ejemplo resaltado .mi-clase, :hover. Puntaje resaltado (0, 0, 1, 0).Peldaño 2: Texto "Identificadores (IDs)". Código de ejemplo resaltado #mi-id. Puntaje resaltado (0, 1, 0, 0).Peldaño 1 (Cima, el más estrecho): Texto "Estilos en Línea (Inline)". Código de ejemplo resaltado style="color: red;". Puntaje resaltado (1, 0, 0, 0). Etiqueta a un lado: "Mayor peso (Específico)".

> "Infografía educativa minimalista de código CSS sobre transform: translate. Estilo diagrama técnico limpio, fondo blanco puro, tipografía monospace para el código. Diseño en dos bloques:
> 
> Bloque Superior (Sintaxis): Mostrar el código transform: [translate]([eje-x], [eje-y]);. Importante: El texto de cada término debe tener su color específico: 'translate' en morado, 'eje-x' en rojo y 'eje-y' en azul. De cada palabra sale una flecha de su mismo color apuntando a su etiqueta descriptiva: 'Desplazar de su posición' (morada), 'Derecha/Izquierda' (roja) y 'Abajo/Arriba (Valores negativos suben)' (azul).
> 
> Bloque Inferior (Ejemplos): Título 'Ejemplos:' en negro.
> 
> Renglón 1: Código transform: translate(0px, -10px); (con texto gris al lado: 'Efecto de flotar hacia arriba en el hover').
> 
> Renglón 2: Código transform: translate(20px, 0px); (con texto gris al lado: 'Mover el elemento a la derecha').
> 
> Estilo visual: Alta resolución, vectores definidos, limpieza absoluta para facilitar la lectura en clase."
