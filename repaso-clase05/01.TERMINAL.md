# APUNTE 01: LA TERMINAL

## 1. Concepto Central

La terminal no es una herramienta para "escribir código", es una herramienta para **controlar el sistema operativo**. Todo lo que se hace con clics (crear carpetas, mover archivos, abrir programas), se puede hacer más rápido con comandos.

## 2. Los 4 Comandos Esenciales (El Cuchillo Suizo)

| Comando          | Significado             | Qué hace en la vida real                                               | Analogía                                                |
| ---------------- | ----------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------- |
| `pwd`            | Print Working Directory | Te dice tu ubicación exacta en la computadora.                         | Ver el GPS o el letrero de la calle donde estás parado. |
| `ls`             | List                    | Muestra todos los archivos y carpetas visibles en tu ubicación actual. | Abrir los ojos y mirar qué hay en la habitación.        |
| `cd [ruta]`      | Change Directory        | Te mueve a otra carpeta. Ej: `cd Documents`.                           | Caminar hacia otra habitación.                          |
| `cd ..`          | -                       | Te mueve una carpeta hacia arriba (al padre).                          | Retroceder por la puerta por la que acabas de entrar.   |
| `mkdir [nombre]` | Make Directory          | Crea una nueva carpeta.                                                | Construir una nueva habitación en la casa.              |

## 3. Puntos de Fricción en Clase (Dónde se equivocan los alumnos)

1. **Espacios en los nombres:** Si escriben `cd Mi Carpeta`, la terminal cree que son dos comandos. Deben usar comillas `cd "Mi Carpeta"` o evitar espacios `cd MiCarpeta`.
2. **Mayúsculas/Minúsculas:** La terminal es case-sensitive. `desktop` no es lo mismo que `Desktop`.
3. **Pánico de "No funciona":** El error más común es intentar entrar a una carpeta que no está en la ubiación actual. _Solución: Siempre diles que hagan `ls` antes de hacer `cd` para asegurarse de que la carpeta existe ahí._

## 4. El "Atajo de Vida" para enseñar

- **La tecla TAB:** Escribes `cd Doc` y presionas `TAB`, la terminal autocompleta `cd Documents`. Esto les vuela la cabeza a los alumnos y acelera la clase un 50%.
- **Flecha Arriba:** Para repetir el comando anterior sin volver a escribirlo.

## 5. El Comando Final del Setup

`code .` → Abre Visual Studio Code exactamente en la carpeta donde estás parado. (El punto `.` significa "esta carpeta").
