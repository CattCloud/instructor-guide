HTML5 Semántico — Estructura la web con sentido

Etiquetas con significado, accesibilidad desde el día uno y formularios que funcionan para todos

1. Etiquetas Semánticas

Las etiquetas HTML5 describen el rol del contenido — no solo su apariencia visual.

<header> — encabezado del sitio o sección
<nav> — menú de navegación principal
<main> — contenido único de la página
<section> — bloque temático dentro de main
<article> — contenido autónomo reutilizable
<footer> — pie del sitio o sección

2. Jerarquía de Encabezados

El orden h1 → h2 → h3 crea la estructura lógica que leen los screen readers y los motores de búsqueda.

<h1>Nombre del producto</h1>        ← Solo uno por página
  <h2>Características</h2>              ← Secciones principales
    <h3>Diseño intuitivo</h3>          ← Subsecciones
  <h2>Planes</h2>                        ← Siguiente sección

3. Accesibilidad (A11y)

Prácticas que hacen el sitio usable para todas las personas — con o sin lectores de pantalla.

<!-- Texto alternativo en imágenes -->
<img src="logo.png" alt="Logotipo de la empresa">
<img src="banner.jpg" alt="">  ← decorativa: alt vacío

<!-- ARIA cuando la semántica nativa no alcanza -->
<nav aria-label="Menú principal"></nav>
<button aria-label="Cerrar modal">✕</button>

4. Formulario Accesible

Cada <input> necesita su <label for> — sin esa conexión el lector de pantalla no anuncia el campo.

<form>
  <label for="nombre">Nombre</label>
  <input type="text"  id="nombre" name="nombre">

  <label for="email">Correo</label>
  <input type="email" id="email"  name="email">

  <button type="submit">Enviar</button>
</form>

Regla de oro: el for del label debe coincidir con el id del input.

Si al hacer clic en el texto del label el cursor salta al input → la asociación está bien.

Nunca: placeholder no reemplaza al label — desaparece al escribir.

A11y "accessibility" — prácticas para que productos digitales sean usables por todos.
ARIA Atributos que mejoran la accesibilidad cuando el HTML nativo no alcanza.
Screen reader Software que convierte el texto de la página en audio para navegar el sitio.
Tab nav Navegar por el sitio solo con la tecla Tab — la prueba definitiva de A11y.
