# Clase 05: Setup del Desarrollador Moderno

## Resumen

Bienvenido al Módulo 2. En las próximas 4 clases, dominarás las herramientas que usan los desarrolladores profesionales todos los días: terminal, Git, DevTools, y herramientas de IA.

En esta primera clase, aprenderás a usar la terminal—esa pantalla negra con texto que parece de película de hackers—y Git, el sistema que permite a equipos de miles de desarrolladores trabajar en el mismo código sin pisarse. Al final, tendrás tu proyecto MyLinks clonado desde GitHub y habrás hecho tu primer push.

**Proyecto del Módulo:** MyLinks - Tu Hub Personal en la Web (como Linktree, pero tuyo)

---

## ¿Por qué te sirve?

- **La terminal es el control remoto universal de tu computadora.** Tareas que tomarían 10 clics en interfaces gráficas se hacen en un comando. Los desarrolladores profesionales viven en la terminal porque es más rápida y poderosa.

- **Git es el seguro de vida de tu código.** ¿Rompiste algo? Git te permite volver atrás. ¿Quieres probar algo arriesgado? Git te permite hacerlo sin miedo. Es como tener "Ctrl+Z" para todo tu proyecto.

- **GitHub es tu portfolio profesional.** Cuando busques trabajo, los reclutadores revisarán tu GitHub. Cada commit es evidencia de tu progreso como desarrollador.

---

## 🎯 ¿Qué haremos en clase?

1. **Conocerás la terminal** - Navegarás por carpetas, crearás archivos y ejecutarás comandos básicos sin tocar el mouse.

2. **Configurarás Git** - Instalarás y configurarás Git con tu identidad para que tus commits tengan tu nombre.

3. **Clonarás tu primer repositorio** - Copiarás el template de MyLinks desde GitHub a tu computadora local.

4. **Harás tu primer commit y push** - Modificarás el proyecto, guardarás los cambios en Git, y los subirás a GitHub.

---

## Objetivos de Aprendizaje

Al finalizar esta clase, podrás:

1. **Navegar** por el sistema de archivos usando comandos de terminal (`cd`, `ls`, `pwd`)
2. **Explicar** qué es Git y por qué es esencial para el desarrollo de software
3. **Clonar** un repositorio de GitHub a tu computadora local
4. **Crear** commits con mensajes descriptivos
5. **Subir** cambios a un repositorio remoto con `git push`

## Glosario

| Término | Definición |
|---------|------------|
| **Terminal** | Interfaz de texto para ejecutar comandos en el sistema operativo |
| **CLI** | Command Line Interface - otra forma de llamar a la terminal |
| **Git** | Sistema de control de versiones para rastrear cambios en el código |
| **GitHub** | Plataforma en la nube para almacenar repositorios Git |
| **Repositorio** | Carpeta que contiene el proyecto y su historial de cambios |
| **Clone** | Copiar un repositorio remoto a tu computadora local |
| **Commit** | Guardar un punto en el historial con los cambios realizados |
| **Push** | Subir los commits locales al repositorio remoto |
| **Remote** | Servidor donde se almacena la versión central del repositorio |
