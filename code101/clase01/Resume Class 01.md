# Clase 01: Setup y Web Moderna

## Resumen

En esta primera clase, descubrirás cómo funciona la web moderna—desde que escribes una URL hasta que ves una página en tu navegador. Es un viaje fascinante que involucra clientes, servidores, protocolos y código.

Configurarás tu entorno de desarrollo profesional con Visual Studio Code, el editor que usan millones de desarrolladores en el mundo. Instalarás extensiones que te permitirán ver cambios en tiempo real mientras escribes código.

Al final de la clase, tendrás tu primera página web funcionando: una página con tu nombre, una foto tuya, una breve bio y una lista de tus hobbies. Es el primer paso de un proyecto que evolucionará durante las próximas 4 clases hasta convertirse en tu perfil personal completo.

---

## ¿Por qué te sirve?

- **HTML tiene más de 30 años y sigue siendo la base de toda la web.** Frameworks y tecnologías van y vienen, pero HTML permanece. Lo que aprendas hoy te servirá toda tu carrera.

- **El modelo cliente-servidor no solo aplica a páginas web.** Es el mismo que usa Netflix cuando ves una película, Spotify cuando escuchas música, o cualquier app en tu teléfono que se conecte a internet.

- **Configurar bien tu entorno desde el inicio te ahorra horas después.** Los profesionales invierten tiempo en sus herramientas porque saben que una buena configuración multiplica su productividad.

---

## 🎯 ¿Qué haremos en clase?

1. **Exploraremos cómo funciona la web** - Descubrirás qué pasa "detrás de escenas" cuando visitas un sitio web y verás que todo sitio está hecho de código que puedes leer.

2. **Configurarás tu entorno profesional** - Instalarás VS Code y las extensiones que usan los desarrolladores reales: Live Server, Auto Rename Tag y Prettier.

3. **Crearás tu primera página web** - Escribirás HTML real y verás los resultados actualizarse en tiempo real cada vez que guardes.

4. **Mostrarás tu trabajo** - Presentarás tu página al grupo y verás lo que crearon tus compañeros.

---

## Objetivos de Aprendizaje

Al finalizar esta clase, podrás:

1. **Explicar** el ciclo básico de una petición web (cliente → servidor → respuesta)
2. **Configurar** VS Code con las extensiones necesarias para desarrollo web
3. **Crear** un archivo HTML con estructura básica válida
4. **Utilizar** Live Server para ver cambios en tiempo real
5. **Implementar** etiquetas HTML básicas: `<h1>`, `<p>`, `<img>`, `<ul>`, `<li>`

## Glosario

| Término | Definición |
|---------|------------|
| **URL** | Uniform Resource Locator - La dirección única de un recurso en la web |
| **HTTP** | HyperText Transfer Protocol - El protocolo de comunicación de la web |
| **Cliente** | El navegador que solicita información (tu computadora) |
| **Servidor** | La computadora que responde con la información solicitada |
| **HTML** | HyperText Markup Language - El lenguaje de estructura de las páginas web |
| **Etiqueta** | Los elementos que dan estructura al HTML, escritos entre `< >` |
| **Live Server** | Extensión que actualiza el navegador automáticamente al guardar |
