# Clase 09: Fundamentos de JavaScript

## Resumen

Bienvenido al Módulo 3. En las próximas 4 clases, aprenderás a programar con JavaScript—el lenguaje que le da vida a las páginas web. Pasarás de crear sitios estáticos a construir experiencias interactivas donde el usuario puede hacer clic, escribir y recibir respuestas.

En esta primera clase, descubrirás cómo una computadora "piensa" siguiendo pasos lógicos, y aprenderás a expresar esos pasos usando JavaScript. Crearás tus primeras variables, trabajarás con diferentes tipos de datos, realizarás operaciones matemáticas y de texto, y usarás la consola del navegador como tu herramienta de pruebas.

Esta base será clave para construir, en las próximas sesiones, tu primer juego interactivo: **"Adivina el Número"**.

**Proyecto del Módulo:** Adivina el Número - Juego Interactivo

---

## ¿Por qué te sirve?

- **JavaScript es el lenguaje más usado del mundo.** Según Stack Overflow, lleva más de una década como el lenguaje #1. Cada sitio web que visitas—Google, YouTube, Instagram—usa JavaScript. Aprenderlo te abre la puerta a frontend, backend, apps móviles y más.

- **Pensar en algoritmos es una habilidad para toda la vida.** No solo es para código: descomponer problemas en pasos ordenados te sirve para planificar proyectos, resolver conflictos y tomar decisiones. Las empresas buscan personas que piensen de forma estructurada.

- **La consola del navegador es tu laboratorio personal.** Los desarrolladores profesionales la usan todos los días para probar ideas rápidas, depurar errores y entender cómo funciona el código. Hoy aprenderás a usarla como ellos.

---

## 🎯 ¿Qué haremos en clase?

1. **Exploraremos qué es un algoritmo** - Descubrirás cómo descomponer tareas cotidianas en pasos precisos que una computadora pueda seguir.

2. **Crearás tu primer archivo JavaScript** - Conectarás un archivo `.js` a tu HTML y verás cómo el navegador ejecuta tu código.

3. **Experimentarás con variables y tipos de datos** - Guardarás información en variables y descubrirás la diferencia entre textos, números y booleanos.

4. **Usarás operadores y la consola** - Realizarás cálculos matemáticos, concatenarás textos y verificarás todo en la consola del navegador.

---

## Objetivos de Aprendizaje

Al finalizar esta clase, podrás:

1. **Explicar** qué es un algoritmo y cómo se traduce a instrucciones en código
2. **Crear** un archivo JavaScript y enlazarlo correctamente a un documento HTML
3. **Declarar** variables usando `let` y `const` con tipos de datos `string`, `number` y `boolean`
4. **Utilizar** operadores aritméticos (`+`, `-`, `*`, `/`, `%`) y de concatenación
5. **Inspeccionar** valores y resultados usando `console.log()` en la consola del navegador

## Glosario

| Término | Definición |
|---------|------------|
| **Algoritmo** | Secuencia ordenada de pasos para resolver un problema |
| **JavaScript** | Lenguaje de programación que permite agregar interactividad a páginas web |
| **Variable** | Espacio con nombre donde se guarda un dato que puede cambiar (`let`) o no (`const`) |
| **String** | Tipo de dato que representa texto, encerrado entre comillas (`"hola"`) |
| **Number** | Tipo de dato que representa valores numéricos, enteros o decimales (`42`, `3.14`) |
| **Boolean** | Tipo de dato que solo puede ser `true` o `false` |
| **Operador** | Símbolo que realiza una operación sobre valores (`+`, `-`, `*`, `/`, `%`) |
| **console.log()** | Función que imprime información en la consola del navegador |
| **Script** | Etiqueta HTML (`<script>`) que enlaza un archivo JavaScript con la página |
